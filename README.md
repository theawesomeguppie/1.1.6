# Project 1.1.6: The Number Riddle
## Description
This project uses arithmetic in Java by creating a mathematical riddle. The code takes a defined number, performs arithmetic operations, and prints the result of each individual calculation. This verifies the riddle's consistency. In the end, the code always becomes one number (3).

## Code 
* **Original number:** Defines the original number that is used for testing or to perform calculations
* **Calculations:** A series of Java arithmetic, making an algorithm to resolve the original number into the number 3, and showing each step and calculation.
* **Results:** Outputs the final calculated value (3).
* **Test Values:** Tests different test cases (a negative double value, a negative integer value, the number one, the number zero, a positive double value, and a positive integer value) to ensure that the code works to output 3.
